# Tab backgrounds

Official Clash of Clans art from Supercell's fan kit
(https://fankit.supercell.com/d/vkEdmkUCngKw/game-assets), used under
Supercell's Fan Content Policy. Scaled to at most 1920px wide and saved as
JPEG, otherwise unchanged. Each tab's overlay is set in `app/theme.css`
(`.scene-<tab>::before`).

| File | Tab | Fan kit asset |
|---|---|---|
| home-village.jpg | Overview | Scenery_Ingame_Classic |
| players.jpg | Players | Loading_Screen_2014 (only 1257px wide in the fan kit) |
| war.jpg | Wars | Scenery_Ingame_Classic_War |
| capital.jpg | Capital | Loading_Screen_2022_Clan_Capital |
